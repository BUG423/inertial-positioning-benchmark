# IO 实验设计固定范式 (参考 StarIO, arXiv:2507.16121)

> 本文件固定 IO 论文的实验设计内容。无论路径 A (给指南) 还是路径 B (帮跑)，
> 实验"做什么"一律按本范式；"怎么跑"的命令见 `begin-workflow.md`。
> 范式锚定典型 IO 顶会/顶刊论文 (以 StarIO 为模板): 不追求完美，追求够用且站得住。
> 进 Phase 2 前先 Read 本文件，路径 A 把它写成指南，路径 B 按它逐步执行。

## 四块结构 (固定，顺序执行)

| 块 | 必做性 | 一句话 |
|---|---|---|
| 1. 对比实验 | **必做** | 跟 baseline 在多数据集上比 ATE / RTE |
| 2. 消融实验 | 条件性 (模型能拆模块才做) | 逐模块验证贡献 |
| 3. 可选实验 | 可选 (有核心参数/必要才做) | 参数敏感性等 |
| 4. 可视化 | **必做** | CDF + PDE 图 + 轨迹对比图 |

---

## 1. 对比实验 (必做，最核心)

- **怎么跑**: Begin 的 `bash/baseline.sh` 已经把"数据集 × 对比算法"的笛卡尔积写好，
  改顶部 DATA_ROOT 一键铺开，单个失败不中断、结束打印汇总。这是 IO 相比其它方向最省事的地方，
  对比实验可以直接快速跑出来。
- **规模底线 (硬指标，不可低于)**:
  - 开源数据集 **≥ 3 个** (从 6 个里选: RoNIN / TLIO / RIDI / OxIOD / RNINv2 / IMUNet)
  - 对比算法 **≥ 6 个** (Begin 已收录 24+，凑够 6 个轻松)
  - 指标 = **ATE + RTE** (×2)
  - 合计 **≥ 3 × 6 × 2 = 36 个指标格**
- **成功判据**: 这 36 格里 **≥ 90% 达到 SOTA** (约 32 / 36) 即算对比实验非常成功。
  **明确不追求 100%。**
- **战略性取舍 (合理且推荐)**: 数据集太多、算法太多跑不完，或在某些组合上确实打不过 SOTA 时，
  **可以战略性排除部分数据集 / 部分对比算法**，只要守住"≥3 数据集 × ≥6 算法 × 2 指标 = ≥36 格、
  ≥90% SOTA"的底线。排除要在论文里给得出理由 (e.g. 该数据集无该 baseline 官方权重 / 该算法未开源)。
- **理想全量**: 资源允许时，把所有对比算法在全部 6 个数据集上各跑一遍最稳，再按结果决定要不要排除。

## 2. 消融实验 (条件性: 模型能拆成模块才做)

- **触发条件**: 你的方法能拆成多个可分离模块 (e.g. 模块 X + 模块 Y)。拆不开就跳过这一块，不硬凑。
- **怎么做**: 在 `network/<算法>/` 里为每个消融变体建一个 arch 名
  (e.g. `<算法>_No_X` / `<算法>_No_Y` / `<算法>_Only_X`)，在 `model_factory.py` 各注册一个分支，
  用同一条训练命令切 `--network` 跑。
- **看什么**: 每去掉一个模块，ATE / RTE 掉多少 (Δ vs full model)，证明每个模块都有贡献。

## 3. 可选实验 (按需，别硬凑)

- 仅当方法里确有**核心超参或必须验证的设计选择** (e.g. 分支数 / temperature / window_size / 坐标系)，
  才做敏感性实验。没有就不做。

## 4. 可视化 (必做，两类图)

### 4.1 CDF + PDE 对比图 (必做)
- **CDF 曲线**: 把你的算法和**部分经典对比算法**拿出来，画它们在**某一个数据集**上 ATE / RTE 的
  累积分布函数 (CDF)。脚本: `plot/cdf_pde/`。
- **判读**: 你的 CDF 曲线应更**靠近左上角** = 小误差样本占比更高 = 收敛性 / 稳定性更好。
- **PDE (误差概率密度图，直方图 / 密度曲线)**: 验证你的算法误差**更集中、整体更低**。
- 范式直接参考 StarIO 的 CDF / PDE 图。

### 4.2 轨迹对比图 (必做)
- **怎么挑**: 先看测试集轨迹，**挑出你的算法误差较低的若干条轨迹** (精选，不是全画)。
- **怎么画**: 把这几条轨迹的"你的算法 vs 对比算法 vs GT"画在同一张图里。
  脚本: `plot/traj/` (全量总览 `plot_all_trajectories.py` + 精选网格图)。
- **目的**: 直观展示你的算法轨迹更贴合真值，补强对比实验的数字。

## 执行顺序
1. 对比实验 (`baseline.sh` 一键铺开，先拿主表)
2. 消融实验 (若模型可拆模块)
3. 可选参数实验 (若有必要)
4. 可视化 (CDF / PDE + 轨迹，从已有 `results/` 出图)

## 落盘
结果按 `templates/experiment-plan.md` 回填: 对比主表 (标 SOTA 命中率 x/36)、消融表、
可选实验、可视化产物清单 (CDF / PDE 图 + 轨迹图路径)。

## 路径 A / 路径 B 怎么用本范式
- **路径 A (给策略指南)**: 按本范式告诉用户"对比 / 消融 / 可视化各要做什么、怎么做"，
  对比实验必做，消融看模型能否拆模块，可选看是否有必要参数，可视化必含 CDF/PDE + 轨迹对比。
- **路径 B (帮跑)**: 先要 SSH (远程) + 代码路径，且代码必须**以 Begin 结构为规范保存**、
  数据按 `<数据集>v2/{train,val,test}.txt + all/` 组织; 验证通过后完全按本范式逐步设计并执行。
