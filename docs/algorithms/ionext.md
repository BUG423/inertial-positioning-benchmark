## 3. 输出

- “The network output is the average velocity over the unit time window”：每个窗口一个平均速度向量。维度未明示；与 RoNIN 基线一致取 **D=2**（水平，m/s）。
- 无协方差/不确定度。
- 轨迹：“trajectories are reconstructed by integrating the predicted velocity sequence” → IPB §5 统一重建。

## 4. 网络结构

整体：stem →（4 个阶段，深度 `[2, 2, 6, 2]`，通道 `[96, 192, 384, 768]`，阶段间用 k=2、s=2 的非重叠卷积下采样）→ 头。每个阶段由 ADE（Adaptive Dynamic Encoder）块堆叠；无位置编码、无注意力。

- **参数总量（本规格，D=2）：10,641,506**；D=3 时 10,642,275。论文 v1 表 I 报告 **Params 1.1×10⁷**，与本规格一致（到两位有效数字）。
- 计算量：本规格在 T=200 下卷积+线性层的乘加次数（MACs）为 35,587,584；v1 表 I 报告 FLOPs 7.3×10⁷（未注明 T 与计数口径），约为 MACs 的 2 倍，与“FLOPs = 2×MACs”的口径相符（未核实）。
- 标 **[假设]** 的层论文没有写：stem 后/下采样前的归一化、头部结构。选择依据：论文称结构“借鉴 Swin/ConvNeXt 的 stem 与下采样层”，ConvNeXt 在 stem 后与每个下采样卷积前各有一个归一化，头部为“归一化 + 全局平均池化 + 线性层”；论文消融 (v) 说明全网用 BN 优于 LN，所以这些归一化取 BN。它们只贡献 4,074 个参数，不影响“1.1×10⁷”的核对。
- 所有卷积 `bias=True`（论文未说明，PyTorch 默认）。初始化未说明：用 PyTorch 默认初始化。
- 无 ReLU/GELU：ADE 中的非线性只有 softmax 融合权重、sigmoid 门控与乘法交互（论文未提及其他激活）。

### 4.2 ADE 块（通道 C，h = C/2，时间长度 T_s）

`X' = X + ADM(BN(X))`；`X_out = X' + AGU(BN(X'))`（v2 式 (1)(2)，预归一化残差）。

| 步 | 操作 | 形状 | 参数量 |
|---|---|---|---|
| a | `BN₁ = BatchNorm1d(C)` | (B, C, T_s) | 2C |
| b | 沿通道均分：`X₀ = x[:, :h]`，`X₁ = x[:, h:]` | (B, h, T_s) ×2 | 0 |
| c | 翼 0 多尺度：3 个并行深度卷积 `Conv1d(h, h, k, padding=k//2, groups=h)`，`k ∈ (1, 3, 11)` → `Y₀,₀..Y₀,₂` | 各 (B, h, T_s) | 2h + 4h + 12h |
| d | 翼 0 融合权重：`GAP_T(X₀)` → (B, h, 1) → `W1₀ = Conv1d(h, 3h, 1)` → (B, 3h, 1) → 按通道顺序切成 3 段并 reshape 为 (B, 3, h, 1) → **在分支轴（dim=1）上 softmax** → `ω₀,ᵢ` | (B, 3, h, 1) | 3h² + 3h |
| e | `F₀ = Σᵢ Y₀,ᵢ ⊙ ω₀,ᵢ`（逐通道广播相乘） | (B, h, T_s) | 0 |
| f | 翼 1：同 c，`k ∈ (1, 5, 17)` | 各 (B, h, T_s) | 2h + 6h + 18h |
| g | 翼 1 融合权重：同 d，`W1₁ = Conv1d(h, 3h, 1)` | (B, 3, h, 1) | 3h² + 3h |
| h | `F₁ = Σᵢ Y₁,ᵢ ⊙ ω₁,ᵢ`；`W2 = Conv1d(C, C, 1)` 作用于 `concat(F₀, F₁)` | (B, C, T_s) | C² + C |
| i | 残差：`X' = X + ADM(...)` | (B, C, T_s) | 0 |
| j | `BN₂ = BatchNorm1d(C)` 得 `Z` | (B, C, T_s) | 2C |
| k | AGU 门控支路：`concat(GAP_T(Z), GMP_T(Z))`（平均池化与最大池化沿时间维，按通道拼接） → (B, 2C, 1) → `W3 = Conv1d(2C, C, 1)` → sigmoid → `ξ` | (B, C, 1) | 2C² + C |
| l | AGU 值支路：`DWConv = Conv1d(C, C, 3, padding=1, groups=C)` **[核大小假设为 3]** | (B, C, T_s) | 4C |
| m | `ξ ⊙ DWConv(Z)`；残差：`X_out = X' + …` | (B, C, T_s) | 0 |

- 单块参数量：`4.5·C² + 35·C` → ADE(96)=44,832；ADE(192)=172,608；ADE(384)=676,992；ADE(768)=2,681,088（其中 ADM(96)=25,536，AGU(96)=18,912，其余为两个 BN）。
- 核组 `(1, k, 3k+2)`，`k ∈ {3, 5}`：翼 0 取 k=3 → (1, 3, 11)，翼 1 取 k=5 → (1, 5, 17)（v1 表 I 每个阶段都写 “(1, 3, 11; 1, 5, 17)”）。所有阶段相同。
- 深度卷积 `padding = k // 2`，保持时间长度（论文未写填充方式，这是唯一能让三个分支相加的选择）。

## 8. 忠实性测试建议（参数量为本规格的解析计数，不是官方代码）

- [ ] 总参数量：D=2 时 == 10,641,506；D=3 时 == 10,642,275
- [ ] 单个 ADE 参数量 == `4.5·C² + 35·C`（C ∈ {96, 192, 384, 768}）；阶段参数量依次为 89,664 / 382,464（含下采样 BN+Conv）/ 4,210,176 / 5,953,536，stem（含 BN）2,592，末端 BN+头 3,074
- [ ] 形状：T=200 时 stem 输出 (B,96,50)，各阶段输出时间长度依次 50 / 25 / 12 / 6，最终 (B, D)；T=100 时依次 25 / 12 / 6 / 3
- [ ] 融合权重：每个翼的 `ω` 形状 (B, 3, h, 1)，沿分支轴求和为 1（误差 < 1e-6），且非负
- [ ] 门控：`ξ` 形状 (B, C, 1)，取值在 (0, 1)
- [ ] 退化检查：把 `W1` 的权重与偏置置 0 → `ω ≡ 1/3`，ADM 输出等于 `W2(concat(mean_i Y₀,ᵢ, mean_i Y₁,ᵢ))`；把 `W3` 权重置 0、偏置置 +∞ 近似（如 50）→ AGU 退化为纯深度卷积
- [ ] 通道置换等价：输入通道置换 π 且 stem 权重按 π 置换后，输出逐元素一致（证明输入顺序无关）
- [ ] 深度卷积为真正的 depthwise：`groups == in_channels`，每个 DW 卷积权重形状 `(h, 1, k)`，核集合为 {1,3,11} 与 {1,5,17}
- [ ] 残差恒等：把两个子模块输出置 0 时 ADE 为恒等映射
- [ ] `eval()` 下输出与 batch 组成无关（BN 使用滑动统计）

## 10. 官方实现的坑与未决问题

1. **没有代码，v1/v2 结构描述不一致**：
   - v1 的 STGU 称“为每个时间步计算权重”（门控在时间轴），v2 的 AGU 明确 `ξ ∈ R^{C×1}`（门控在通道轴）。按 v1 的时间轴门控，`W3` 只剩 2→1 的逐点卷积，总参数量约 6.3×10⁶，与 v1 自己表 I 的 1.1×10⁷ 不符；按 v2 的通道轴门控得 1.06×10⁷，与表 I 相符。**因此采用 v2**。
   - v1 式 (5) 在每个翼的多尺度卷积前还有一个 BN（`DWConv(BN(X_j))`），v2 式 (4) 没有。采用 v2（差异仅 4 个 BN，参数可忽略）。
2. **softmax 的轴**：v2 写 “softmax (applied along the channel dimension)”，而权重是 3h 维、之后再切成 3 段。“沿全部 3h 个通道做 softmax”会使每个通道的权重小到约 1/(3h)，与“多尺度融合系数”的语义不符；本规格取“每个通道在 3 个分支之间 softmax”，并保留 `softmax_axis ∈ {branch, channel}` 配置项。
3. **v2 式 (2) 与式 (9)–(12) 记号不一致**：式 (2) 把 `BN(X')` 送入 AGU，式 (9)–(12) 写的是 `X'`。本规格按式 (2) 取 `BN(X')`。
4. 未定义的部分：stem/下采样/头部的归一化与结构、AGU 值支路核大小、卷积 bias、初始化、调度器、增强、训练步长。全部在本卡标为 [假设] 或“未给出”。
5. 数据划分为随机 8:1:1 重划分，论文数值与使用官方划分的工作不可比；长度归一化指标 ×100 的表述容易被误读为米。
6. v1 摘要中的“相对 iMOT 降低 10%/12%”与 v1 正文“降低 45.5%/46.8%”彼此矛盾，v2 已改为绝对差值；引用时以 v2 表 I 为准。
