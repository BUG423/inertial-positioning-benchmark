## 3. 输出

- 每个轴 `i ∈ {x, y, z}` 一个 **N 个箱上的概率分布** `π_i = {π_{i,0}, …, π_{i,N−1}}`（softmax 归一化，式 4）[P]。三个轴的分布相互独立（**不是**二维/三维联合分箱）。
- **速度（期望解码）**：`v̂_i = Σ_n π_{i,n} b_n`（式 1）[P]，`b_n` 为箱中心；单位 m/s，机体系。
- **不确定度（方差解码）**：`σ̂_i² = Σ_n π_{i,n} (b_n − v̂_i)²`（式 2）[P]，即同一分布围绕解码均值的方差；**没有单独的协方差解码器**。
- EKF：`z_k = v̂_k`，`h(X_k) = R_kᵀ · G v_k`，`Σ̂_k = diag(σ̂_x², σ̂_y², σ̂_z²)`（式 11–12），**直接用作量测协方差，不做缩放，也不做 innovation 门限** [P]。
- IPB：`{"vel": (B,3), "logstd": (B,3)}`，`logstd_i = ½ log σ̂_i²`；`target=velocity_at_end` 或 `avg_velocity`（见 §6 与 §10 第 3 条）。

### 3.1 分箱定义

- 每个轴共享同一个操作区间 `[v_min, v_max] = [−R, R]`，`R ≈ 1.1 × 训练集逐轴最大速度`（**每个数据集单独设定**）[P]。
- 箱中心向量 `b = (b_0, …, b_{N−1})`；箱 n 的边界取相邻中心的中点：`b_n^+ = ½(b_n + b_{n+1})`、`b_n^- = ½(b_{n−1} + b_n)`；首尾箱的外边界分别延伸到 `v_min`、`v_max` [P]。
- 箱中心是否等间距，论文没有明说 [A]：取**均匀网格** `b_n = −R + (n + ½)·Δ`、`Δ = 2R/N`（这样中点边界恰好落在均匀格点上，与“discretize into N bins”一致）。
- `N = 512`（默认）[P]；消融扫过 16…2048。
- **诚实要求**：`R` 只能用训练划分统计，不能看 val/test。

## 4. 网络结构

### 4.1 编码器（沿用 AI-IO，论文未给细节）

“Per-modality 1-D convolutions and a two-layer transformer encoder map the input window … to a last-step feature `h ∈ R^{D_h}`”，`D_h = 48` [P]。卷积核大小、通道数、transformer 的头数与 FFN 宽度**均未给出** [A]。本卡的参考配置（用于推导参数量，实现时可在配置中调整并记录）：

| # | 层 | 参数 | 输出形状（T=200） |
|---|---|---|---|
| 0 | 输入（IPB：`[acc(3), gyro(3)]`；官方另有 `rotor(4)`） | — | (6, 200) |
| 1 | 每模态 1D 卷积支路 ×2（官方 ×3）：`Conv1d(c_in, W, k=5, pad=2) → ReLU → Conv1d(W, W, k=5, pad=2) → ReLU`，IPB 取 `W=24`（官方 `W=16`，三支路拼接后同为 48） | IPB 6,672；官方 4,736 | (48, 200) |
| 2 | 拼接 → 转成 token 序列 `(T, 48)` | 0 | (200, 48) |
| 3 | `TransformerEncoder(TransformerEncoderLayer(d_model=48, nhead=4, dim_feedforward=192, batch_first=True), num_layers=2)` | 56,448 | (200, 48) |
| 4 | 取最后一个 token → `h` | 0 | (48,) |

（位置编码是否加在 token 序列上、是否有 dropout，论文未写 [A]：默认不加位置编码、dropout=0.1 沿用 PyTorch 默认。）

### 4.2 分箱解码器（论文给了精确公式与参数量）

```text
SPE(b) = sin(γ ⊙ PE(b)) ∈ R^{N×C}          # PE(b): 箱中心的固定正弦位置编码；γ ∈ R^C 可学习的逐通道频率（式 3）
e_n    = φ(SPE(b_n)) ∈ R^D                 # φ: Linear(C → D)，所有轴与所有箱共享
q_i    = θ_i(h) ∈ R^D                      # θ_i: Linear(D_h → D)，每个轴一个
π_{i,n} = exp(q_i · e_n) / Σ_m exp(q_i · e_m)   # 式 4：查询与“箱坐标分类器”的内积后 softmax
```

- 超参数：`D_h = 48`，`C = 64`，`D = 32` [P]。
- 参数量 `= C + D(C+1) + 3D(D_h+1) = 64 + 2,080 + 4,704 = 6,848`（≈6.8 k）[P]，**与箱数 N 无关**——这是用“箱坐标分类器”替代 `Linear(D_h → 3N)` 的核心好处：后者在 N=512 时需要 `3N(D_h+1) = 75,264` 参数 [P]。本卡用原型实现核对，得到的就是 6,848，与论文一致。
- 论文报告编码器 69.8 k 参数，解码器为其 9.8%（6.8 k）[P]；总计约 76.6 k。
- 推导值（本卡参考配置）：IPB 版（无 rotor 支路）**69,968**；官方形状（含 rotor 支路）68,128。两者都比论文的 76.6 k 少约 9%–10%，差异全部落在未公开的编码器细节上。
- 初始化：`γ` 的初值未给出 [A]：取全 1（此时 `SPE = sin(PE)`）；其余用 PyTorch 默认。

## 5. 损失与训练配方（official）

### 5.1 误差条件高斯标签（本方法的核心监督）

```text
v_e,i = |v̂_i − v_i|                     # 逐轴速度误差；构造标签时 detach，不回传（式 5）
σ_i   = max(v_e,i, Δ/10)                # Δ 为箱宽；论文把 σ 下限设为 1/10 箱宽
q̄_i   = N(v_i, σ_i²)                    # 以真值速度为中心的高斯（式 5）
q_{i,n} = (1/Z_i)[Φ((b_n^+ − v_i)/σ_i) − Φ((b_n^- − v_i)/σ_i)]      # 在每个箱的支撑上积分（式 6，HL-Gauss 直方图口径）
q_{i,n} ← (1/Z̃_i) q_{i,n} exp(η_i b_n)  # 指数倾斜，使 Σ_n q_{i,n} b_n = v_i 精确成立（式 7）；η_i 在 autograd 之外求解
```

- 标签宽度**随当前样本的误差自适应**：误差小 → 标签尖锐；误差大 → 标签平缓（Fig. 3）[P]。论文的理由：`E[σ_i²] = E[v_{e,i}²] = Var[v̂_i − v_i]`，所以标签方差是边缘误差方差的无偏目标 [P]。
- 倾斜（式 7）修正了式 6 的离散化偏差，只二阶地改变标准差；当式 6 的解码均值已经精确时 `η_i = 0` [P]。求解 `η_i` 的具体数值方法未给出 [A]（建议 Newton 或二分，`Σ_n q_n e^{η b_n}(b_n − v_i) = 0` 单调，容差 1e-8，迭代上限 50）。

### 5.2 训练目标

| 项 | 值 | 来源 |

- [ ] 解码器参数量 `== 6,848`（`D_h=48, C=64, D=32`，3 个轴），且**与 N 无关**：N=16 与 N=2048 的参数量相同；对照 `Linear(D_h, 3N)` 在 N=512 时为 75,264。
- [ ] 本卡参考配置总参数量：IPB（无 rotor）69,968；官方形状（含 rotor）68,128。两者都要在配置里注明“论文报告约 76.6 k（编码器 69.8 k + 解码器 6.8 k）”。
- [ ] 形状：输入 `(4,6,200)` → `π (4,3,512)`（或 `(4,3,N)`）、`vel (4,3)`、`logstd (4,3)`；`π` 沿箱维求和为 1（容差 1e-6）。
- [ ] **期望解码**：`π` 为 one-hot 在第 n 个箱上时 `v̂ = b_n`、`σ̂² = 0`；`π` 为两个相邻箱各 0.5 时 `v̂` 为两中心的中点，`σ̂² = (Δ/2)²`。
- [ ] **解码方式切换**：`argmax` 与 `expectation` 在同一 `π` 上的差 ≤ `R`（平凡上界），且当 `π` 单峰对称时两者差 ≤ Δ/2；`topk_expectation(k=N)` 必须与 `expectation` 逐位相等。
- [ ] **标签构造**：给定 `v`、`σ`，式 6 的 `q` 沿箱维求和为 1；`σ` 越小分布越尖（熵单调下降）；式 7 倾斜后 `Σ_n q_n b_n == v`（容差 1e-6，`v` 在 `[−R+Δ, R−Δ]` 内）；`σ` 被 clamp 到 `Δ/10` 时标签至少覆盖一个箱的非零质量。
- [ ] **KL 损失**：`π == q` 时为 0；`q` 已 detach（`q.requires_grad == False`），`σ` 不回传梯度（构造图中 `v_e` 被 detach）。
- [ ] **Huber**：`δ=0.1`，在 `v_e = δ` 处一阶连续（数值导数左右差 < 1e-6）。
- [ ] 不确定度与误差的相关性（训练后的行为性质，不作为硬性单元测试）：在验证集上 `σ̂²` 与 `(v̂ − v)²` 的相关系数应显著为正，NEES 中位数接近 3（3 维）。
- [ ] `R` 的来源：断言 `R` 由训练划分统计得到（配置里记录数值与来源），并且 `|v_target|` 超出 `[−R, R]` 的训练窗口比例被记录（论文未规定越界样本的处理，见 §10）。

## 10. 官方论文的坑与需要假设的地方

1. **编码器细节全部缺失**：论文只说“沿用 AI-IO 的编码器：逐模态 1D 卷积 + 两层 transformer，输出 `h ∈ R^48`”，卷积核/通道/头数/FFN 宽度/是否有位置编码都要查 AI-IO 原文（另一篇论文，本卡未获取）。因此 §4.1 的配置与 69,968 的参数量都是假设值；解码器部分（6,848）则可由论文公式精确复现。
2. **箱中心是否均匀未明说**：只说“discretize into N bins”并给出中点边界规则。本卡取均匀网格；若实现成非均匀（例如按速度分布分位数），式 6/式 7 仍成立，但 `Δ/10` 的 σ 下限与 `argmax` 的量化误差上界都要改写。
3. **速度目标的时刻未定义**：论文说预测“body-frame velocity”，但没说是窗口末端速度、窗口中心速度还是窗口平均速度（AI-IO 的约定未在本文复述）。IPB 默认取 `avg_velocity`，并提供 `velocity_at_end` 变体；两者会改变 `R` 的统计与误差量级，必须在配置中显式声明。
4. **越界样本没有规定**：如果 `|v| > R`（例如 val/test 出现比训练更快的运动），标签会被截断到首/尾箱，期望解码也无法超过 `b_{N−1}`。这是分箱表示的固有上限，论文只在“局限”里提到箱网格按数据集固定。IPB 需要记录越界比例，并在跨数据集迁移时重新统计 `R`（重新统计会改变输出层语义，等同于换模型）。
5. **`η_i` 的求解细节缺失**：式 7 只说“在 autograd 之外由均值约束确定”。本卡建议单调牛顿/二分法并给出容差；不同实现会带来 `O(1e-6)` 级标签差异。
6. **`SPE` 的基底 `PE(b)` 未定义**：论文只写“fixed positional encoding of the bin centers”。本卡假设为 Transformer 式正弦编码，把箱中心（或箱序号）作为位置、`C=64` 个通道；`γ` 初值取全 1。这直接影响 Table IV 中 `SPE` 优于 `PE` 的复现。
7. **`σ_i = |v̂_i − v_i|` 依赖当前预测**：标签随训练过程漂移（自举监督）。训练早期误差大 → 标签极平缓；因此**必须**保留 Huber 项（论文 Table III 也显示 `G+H` 优于 `G`），否则分布可能长时间发散。实现时建议记录每个 epoch 的平均 `σ/Δ`，作为训练健康指标。
8. **NLL 与 NEES 的定义只给了引用**（[36]、[12]），文中没有公式；IPB 若要报告这两个量，需要自己定义并写入 `docs/METRICS.md`。
9. **执行器输入是方法前提的一部分**：AVE/ATE 的领先幅度是在有 RPM/PWM 的空中平台上取得的；去掉该支路后（IPB 变体）分箱头的收益需要重新验证，不能引用论文的百分比。
10. **`Direct` 编码在 AI-IO 数据集上比回归更差**（AVE 0.308 vs 0.263），说明“分箱本身”并非无条件优于回归，箱编码方式与监督方式同样关键；做对照实验时应同时跑 `Direct`、`PE`、`SPE` 三种箱编码。
