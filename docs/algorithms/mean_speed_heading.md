# 平均速度 + 航向常速基线（`mean_speed_heading`）

> 规格卡版本：v1（2026-09-17）· fidelity：`definition`（经典非学习基线，本卡即定义）· 夹具：无（没有神经网络参数）

## 1. 元信息

| 项 | 值 |
|---|---|
| 方法来源 | IPB 定义的最简基线：速度大小取训练集平均水平速度，方向取设备（或参考）姿态给出的航向。与 `pdr.md` 共用航向定义与 δ 标定 |
| 官方仓库 | 无 |
| 许可 | 不适用 |
| 框架 | numpy |
| fidelity | `definition` |
| 目的 | 给出“完全不看 IMU 运动信息、只知道朝向”的下界；与 `pdr` 对比可以看出步检测/步长带来的增益，与学习方法对比可以看出速度大小估计的价值 |

## 2. 任务（输入）

| 项 | 定义 | IPB 映射 |
|---|---|---|
| 采样率 | 200 Hz | 200 Hz |
| 窗口 | 与被比较模型相同 | `window=200` |
| 训练步长 | 只用于标定 | `stride=10` |
| 推理步长 | 与被比较模型相同 | `eval_stride=10` |
| 坐标系 | 只输出世界系水平速度；主变体不读取 IMU 数值 | `frame=gravity_world` |
| 姿态来源 | 与 `pdr` 相同：`device`（常值偏航对齐后的 `imu/orientation`）或 `reference`（`pose/orientation`） | 跟随视图 `orientation` |
| 去重力 | 不适用 | `remove_gravity=false` |
| 通道 | 主变体不使用；门控变体只使用加计 `imu[:, 3:6]` | — |
| 额外输入 | 逐样本姿态 `q_wb`、序列 `body_frame`（同 `pdr`） | 视图需提供 `orientation` |

## 3. 输出

每个窗口的水平平均速度（世界系，m/s），无不确定度：

`v_k = ŝ_k · [cos ψ_k, sin ψ_k]`

- `ψ_k`：窗口航向，按 `pdr.md` 第 4 节第 7–8 步在窗口全部样本上计算（前向轴按 `body_frame` 查表；水平投影太小时换备用轴），再加 δ。
- `ŝ_k`：由变体决定（第 4 节）。
- 轨迹：IPB §5 统一重建。

## 4. 网络结构（不适用 → 变体定义）

| 变体（`variant=`） | `ŝ_k` / `v_k` | 标定量 |
|---|---|---|
| `constant`（**默认**，即本基线） | `ŝ_k = s̄`，对所有窗口相同 | `s̄`、δ |
| `gated` | 运动检测 `m_k = [ std_{t∈窗口}(‖f(t)‖) > σ_th ]`（未滤波比力范数的样本标准差，`ddof=0`）；`ŝ_k = s̄_move` 若 `m_k` 为真，否则 0 | `s̄_move`、δ；`σ_th = 0.5 m/s²`（固定） |
| `zero_velocity`（健全性检查） | `v_k = 0`，轨迹停在锚点 | 无 |
| `train_mean_velocity`（健全性检查） | `v_k = v̄`（不使用航向） | `v̄` |

可学习参数：0。

## 5. 损失与训练配方（不适用 → 标定流程，只用 train 划分）

全部标定使用与被比较模型相同的训练视图：`window=200`、`stride=10`、`frame=gravity_world`、`dims=2`、`target=avg_velocity`，只保留全部样本有效的窗口（DESIGN §3 补充约定）。

| 量 | 定义 |
|---|---|
| `s̄` | `mean_k ‖v_gt,k‖`（所有有效训练窗口，含静止窗口）。注意这是 1 s 平均速度的范数，转弯时小于瞬时速率的平均，这与被预测的目标一致 |
| `s̄_move` | 用**同一个运动检测器**（不是真值）选出 `m_k` 为真的训练窗口，取 `mean ‖v_gt,k‖`。这样测试时的门控与标定时一致 |
| `v̄` | `mean_k v_gt,k`（向量平均）。由于各序列的世界系偏航任意，预期接近 0；它的作用是检查数据是否存在“全局方向偏好” |
| δ | 与 `pdr.md` 第 5 节完全相同（`‖v_gt‖ > 0.5 m/s` 的窗口上求 `ψ_gt − ψ_dev` 的圆均值），并记录 `R̄` |
| 跨数据集 | 使用训练数据集的标定量 |
| 诚实性 | 标定函数只接受 train 序列；结果文件记录全部标定量 |

## 8. 忠实性测试建议（合成数据，确定性）

- [ ] `constant`：所有窗口 `‖v_k‖ == s̄`（误差 < 1e-9）
- [ ] `constant` 与 IMU 数值无关：把加计/陀螺换成随机噪声（姿态不变），输出逐元素不变
- [ ] 偏航等变：把 `q_wb` 左乘 `R_z(α)` → 每个 `v_k` 旋转 α
- [ ] 航向约定：`body_frame=android_device`、设备平放、`R = R_z(30°)`、δ=0 → `ψ_k = 120°`（与 `pdr` 同一测试夹具）
- [ ] 恒定航向直线：§5 重建的终点位移 == `s̄ · (N−1)·dt`（首尾常值外推后速度处处相等，梯形积分精确）
- [ ] `s̄` 标定：合成训练集窗口速度范数已知 → 恢复误差 < 1e-9；δ 标定：已知偏置 0.3 rad → 误差 < 1e-3
- [ ] `gated`：静止窗口（`‖f‖ = g₀ + N(0, 0.05²)`）→ `v_k = 0`；行走窗口（`A = 2 m/s²` 正弦，std ≈ 1.41）→ `‖v_k‖ == s̄_move`
- [ ] `zero_velocity`：重建轨迹恒等于锚点；未对齐 ATE == `sqrt(mean_t ‖p_t − p_0‖²)`
- [ ] `train_mean_velocity`：输出与姿态无关，且等于 `v̄`
- [ ] 泄漏保护：标定函数收到 test 序列 ID 时抛出异常

## 9. 预训练权重

不适用；标定量写入运行目录 `metrics.json`。

## 10. 坑与未决问题

1. 与 `pdr` 相同：航向依赖前向轴约定与设备姿态质量；口袋/包等携带方式下的朝向偏差不能被单一 δ 修正。
2. `s̄` 包含静止窗口，所以 `constant` 变体在行走时低估速度、在静止时凭空移动——这是有意保留的“最朴素”定义，`gated` 变体用于衡量静止检测的作用。
3. `σ_th = 0.5 m/s²` 是经验值（静止手持通常 < 0.3，行走通常 > 1），不在 test 上调。
