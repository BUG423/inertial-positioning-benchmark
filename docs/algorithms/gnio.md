## 3. 输出

- `d̂_k ∈ R³`：窗口内的相对 3D 位移（米），表达在 §2 的重力对齐系中 [P]。
- `u_k ∈ R³`：对数标准差，`Σ̂_k = diag(exp(2u_x), exp(2u_y), exp(2u_z))`（式 11–12）[P]。与 TLIO 相同的对角高斯参数化，但**没有** TLIO 的 `max(u, log 1e-3)` 下限（论文未提及）[A]。
- 官方轨迹：TLIO 的随机克隆 EKF（§III-G）[P]，量测残差 `r = d̂_ij − R_γi^T (p_j − p_i)`，`R_γi` 为克隆 i 的重力对齐偏航旋转。论文的全部数值都是 **EKF 融合后**的结果，没有报告“网络 + 直接积分”的结果。
- IPB：`{"vel": (B,3), "logstd": (B,3)}`，`vel = d̂ / ((T−1)·dt) = d̂ / 0.995 s`，`logstd_vel = u − log(0.995)`；轨迹按 DESIGN §5 积分，不使用 EKF（与 `tlio` 卡同一约定，便于两者对比）。

### 4.2 门控预测头的确切语义（移植要点）

```text
s̃ = Softplus(W_s h + b_s) ∈ R³_{>0}      # 逐轴“速度/幅值提案”，不是标量模长
g  = Tanh(W_g h + b_g)   ∈ [−1, 1]³      # 逐轴门控：符号给方向，绝对值给衰减/置信度
d̂  = s̃ ⊙ g              ∈ R³            # 逐元素乘（Hadamard）
```

- **不是**“模长 × 单位方向向量”的极坐标分解：`s̃` 与 `g` 都是 **3 维逐轴**量，`d̂` 的每个轴独立地被缩放与门控。因此 `‖d̂‖` 没有被显式参数化，`g` 也不是单位向量。
- 结构性约束：`|d̂_i| ≤ s̃_i`；`d̂_i = 0 ⟺ g_i = 0`。静止时网络学习把 `g → 0`，从而“软 ZUPT”地压制幅值支路的噪声 [P]。
- Softplus 保证 `s̃ > 0`（严格非负），所以位移的符号**只**由 `g` 决定；这也是论文 Table IV 中 Tanh 优于 Sigmoid 的原因（Sigmoid 无法翻转方向，RMSE 2.05 → 2.00）[P]。
- 不确定度支路与门控**不共享**参数，直接从 `h_k` 线性映射（式 11）[P]。

### 4.3 参数量（推导值，非官方发布值）

论文 Table I 报告 **4.90 M 参数、0.08 GFLOPs**，TLIO 为 5.42 M / 0.08 GFLOPs [P]（后者与我们 `tlio` 夹具的 5,424,646 一致，说明 Table I 的计数口径与我们相同）。论文没有给出 `W_Q/W_K/W_V` 的维度、注意力头数、以及 `f_k` 是如何从 `(512, 7)` 的主干输出得到 512 维向量的，因此参数量依赖假设。本卡在以下候选中选定 **全局平均池化 + `nn.MultiheadAttention(512, 8)`**，因为它最接近论文报告值：

| 候选（`f_k` 来源 + 注意力实现） | 参数量 | 与 4.90 M 的偏差 |
|---|---|---|
| **GAP + MultiheadAttention(512, 8)（本卡采用）** | **4,934,153** | +0.7% |
| GAP + 手写 `W_Q, W_K ∈ R^{512×d_k}`、`W_V ∈ R^{512×512}`（d_k=512，无偏置） | 4,669,961 | −4.7% |
| GAP + 手写投影（d_k=64 / 128 / 256） | 4,211,209 / 4,276,745 / 4,407,817 | −14% … −10% |
| TLIO 式 FC 颈部（1×1 conv 512→128 + BN + 896→512 + 512→512）+ MultiheadAttention | 5,721,865 | +17% |

- 分解（采用配置）：主干 3,846,144 + Motion Bank 32,768 + 注意力投影 1,050,624 + 三个输出头 4,617 = 4,934,153，全部可训练。
- 若输出改为 2 维（`dims=2`，见 §6）：4,932,614。
- Motion Bank 大小对参数量的影响：m=16/32/64/128 → 4,909,577 / 4,917,769 / 4,934,153 / 4,966,921。
- 计算量核对：仅主干在 T=200 时为 36.8 MMACs ≈ 0.074 GFLOPs，与 Table I 的 0.08 GFLOPs 一致（注意力与头部的贡献 < 1%），这也间接支持“GAP + 轻量注意力”的读法。
- 初始化：论文未提及 [A]。建议主干沿用 TLIO 的初始化（Conv `kaiming_normal_(fan_out)`、BN 1/0、Linear N(0, 0.01²)/0）；`M` 用 N(0, 1)（或 N(0, D^{-1/2})）；注意力用 PyTorch 默认。**建议把 `W_g` 的 bias 初始化为 0**，使初始门控在 0 附近、初始位移接近 0（论文未规定）。

## 8. 忠实性测试建议

paper-only 卡没有官方夹具，下面的数值来自本卡 §4.3 的推导，测试应锁定“本卡规格”而不是“论文值”：

- [ ] 采用配置的参数量 == 4,934,153（GAP + MHA(512,8) + 3 个线性头 + m=64 的 bank）；把 `m` 换成 16/32/128 时分别为 4,909,577 / 4,917,769 / 4,966,921。在卡片与配置中同时记录“论文报告 4.90 M”。
- [ ] 形状：输入 `(4,6,200)` → `d̂ (4,3)`、`u (4,3)`；主干输出 `(4,512,7)`，GAP 后 `(4,512)`。
- [ ] **门控头数学性质**（核心）：
  - `s̃ > 0`（逐元素），`−1 ≤ g ≤ 1`，`|d̂| ≤ s̃`（逐元素，容差 0）。
  - 令 `W_g` 的输出被强制为 0（例如把 `W_g`、`b_g` 置零）→ `d̂ ≡ 0`，即“硬 ZUPT”极限。
  - 令 `b_g` 很大、`W_g=0` → `g → 1`，`d̂ = s̃`，退化为 Softplus 正值回归。
  - 梯度检查：`∂d̂_i/∂s̃_i = g_i`，`∂d̂_i/∂g_i = s̃_i`（数值梯度对比，容差 1e-6）。
- [ ] Motion Bank：`h_k = f_k + c_k`；把注意力权重强制成 one-hot（例如让 `f_k` 与某个原型极度相似）时 `c_k` 等于该原型的 `V` 投影；`M` 参与梯度（`M.grad` 非 None）。
- [ ] 损失：`L_total` 在 `d̂ = d_gt`、`u = 0` 时等于 `λ_NLL · 0.5 · log det I = 0`；把 `λ_NLL` 设为 0 时梯度只来自 MSE；`λ_MSE/λ_NLL = 1e6`（断言配置值，防止移植时“顺手改成 1:1”）。
- [ ] 学习率调度：第 0 步 lr=1e-6，第 5 个 epoch 结束时 lr=1e-4，第 200 个 epoch 末 lr≈1e-6（采样若干步断言单调性与端点）。
- [ ] 位移↔速度换算：`vel · 0.995 == d̂`；`logstd_vel == u − log(0.995)`。
- [ ] 可复用 `gated` 头在 D=512、out=3 时参数量 3,078（对照普通线性头 1,539）；`scale_fn`/`gate_fn` 的五种/两种取值都能前向，且 `pos_elu` 满足 `ELU(x)+1 > 0`。

## 10. 官方论文的坑与需要假设的地方

1. **“两阶段训练”与式 13 矛盾**：正文说“employ a two-stage training strategy using MSE and NLL”，但式 13 是固定权重的静态加和，没有任何按 epoch 的切换；实际的“分阶段”效果来自 λ_MSE=1e2 与 λ_NLL=1e-4 的 10⁶ 倍权重比。移植时按式 13 实现，并把“真两阶段”作为显式标注的变体。
2. **`L_NLL` 的写法不完整**：式 14 写作 `½‖·‖²_Σ̂ + ½ log det Σ̂`，未写 `log 2π` 常数（不影响梯度），也没有 TLIO 的 `logstd` 下限；σ→0 时数值不稳定，需要自己加保护并记录。
3. **注意力细节缺失**：`W_Q/W_K/W_V` 的维度、头数、是否有偏置、是否有输出投影、是否用 LayerNorm/Dropout 都未给出；式 3–6 写成单头缩放点积，正文却称 Multi-Head Attention。参数量因此只能在假设下推导（§4.3 给了四个候选，偏差 −14%…+17%）。
4. **`f_k` 的池化方式未写明**：主干输出是 `(512, T/32)`，论文直接说得到 `f_k ∈ R^D`（D=512）。本卡取全局平均池化，这与报告的 4.90 M 参数、0.08 GFLOPs 最一致；若用 TLIO 的展平 FC 颈部会多出 787,712 参数。
5. **通道顺序自相矛盾**：式 1 写 `m_t = [a_t, ω_t]`（加计在前），正文又说“Following TLIO”（陀螺在前）。本卡按 TLIO 顺序，并要求实现里显式声明。
6. **偏航锚点未说明**：式 1 只说用“current EKF orientation”旋到重力对齐系，没说是否去偏航、以窗口哪个样本为参考；§III-G 的量测残差用窗口起点的 `R_γ`。本卡按 TLIO 处理（去偏航、起点锚定），IPB 用末端锚定并依赖偏航增强等价。
7. **增强、权重衰减、梯度裁剪、选模依据、数据划分全部未写**，本卡按 TLIO 的设置填充并标注为假设；复现结果与论文的差距可能主要来自这里。
8. **Motion Bank 的“查询”只用窗口级特征**：`Q` 是单个 512 维向量（序列长度 1），因此注意力退化为“对 64 个原型做一次加权平均”，没有时间维注意力；`m=128` 反而变差（Fig. 2）与此一致。移植时不要误实现成对时间步的注意力。
9. **数据集列表与结果表不一致**：§IV-B 列出五个数据集（含 TLIO 数据集），Table II 只报告四个；TLIO 数据集只在 Table III/IV 的消融中出现。
10. **论文文本有多处笔误**（例如 “To magnitude these issues”、“archiecture”、“dyanmically”、“effectvely”、“Comparision”），个别相对提升的百分号方向（↑/↓）与数值方向需按表内数字自行核对：例如 IDOL seen 3.45 相对 iMoT 2.22 是变差，表中标为 “↓55.45%”。
